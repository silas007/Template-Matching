# Template Matching

A computer vision practical containing Jupyter notebooks focused on **template matching**: locating a smaller reference image or pattern within a larger image by comparing image regions.

## What this project demonstrates

- The concept of a template and a source image
- Searching an image for a matching region
- Understanding how a best-match location can be identified
- Visual computer-vision experimentation in notebook form

## Repository contents

- `project1.ipynb`
- `project2.ipynb`

Open the notebooks in Jupyter Notebook, JupyterLab or Google Colab and run the cells in order. Check the notebook cells for the specific image inputs, implementation details and outputs used in each exercise.
